# Smart_SignVoice — BicaraUntukku

Aplikasi terjemah bahasa isyarat BISINDO ke teks dan suara berbasis AI untuk Internet Programming II — Polinela.

## Deskripsi
BicaraUntukku adalah aplikasi yang membantu penyandang tunarungu/tunawicara berkomunikasi dengan cara merekam gerakan tangan (isyarat BISINDO) melalui kamera mobile, lalu AI menerjemahkan gerakan tersebut menjadi teks dan suara secara otomatis.

## Tech Stack
- Mobile: Flutter
- Backend: FastAPI (Python)
- Database: PostgreSQL
- Dashboard: React.js
- AI: YOLOv8 + LLM (Gemini API)
- TTS: gTTS (Bahasa Indonesia)

## Dataset
- WL-BISINDO — 1.600 video, 32 kata isyarat (Kaggle)
- BISINDO 39 Kata — dataset tambahan (Kaggle)
