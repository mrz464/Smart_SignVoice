# Dataset BicaraUntukku

## Sumber Dataset
- WL-BISINDO: https://www.kaggle.com/datasets/glennleonali/wl-bisindo
- 1.600 video, 32 kata isyarat BISINDO, 5 penanda tangan

## Cara Pakai
1. Download dataset dari Kaggle
2. Upload ke Google Drive
3. Jalankan preprocess.py di Google Colab
4. Hasil CSV keypoint tersimpan di folder keypoints/
